# 具身机器人科研总览

本文件是项目的中文入口。开始新的分支、实验或大范围修改前，先阅读
[`PROJECT_VISION.md`](PROJECT_VISION.md)，再阅读本文件和对应的任务卡。

## 总目标

围绕机械臂力控、接触操作和人形机器人多接触控制，建立一条可复现、可
解释、可迁移的科研链路：

```text
研究愿景 -> 文献证据 -> 系统/机械设计 -> 实验设计 -> MuJoCo 仿真
-> 数据采集与模型训练 -> 留出条件评测 -> 参数标定与离线回放
-> 监督式真机验证 -> 论文、图表、公式和代码发布
```

当前不预设机器人型号、F/T 传感器、控制器或 ROS 发行版。MuJoCo 是主
仿真平台；硬件命令在安全门禁完成前保持关闭。

## 文献检索与证据

检索分为发现和正式证据两个层次，不能混用：

1. 正式全文优先使用 Web of Science/SCI、IEEE T-RO/RA-L/T-ASE/T-MECH、
   IJRR、Automatica、RSS、CoRL、ICRA、IROS、Nature、Science、Science
   Robotics、Nature Machine Intelligence、CNKI 和万方。
2. OpenAlex、Crossref、Semantic Scholar、arXiv、作者仓储和 AMiner 用于
   发现、去重、引用链和版本交叉核验。
3. 学校门户 App 是 SCI、出版社、CNKI、万方等受限全文的授权入口。登录、
   下载和验证码由本人完成；不要把密码、Cookie、OTP 或会话导出发给
   Codex。

每篇正式使用的论文都要有 DOI/数据库编号、发现源、全文源、访问日期、
PDF 路径、SHA-256 和结构化笔记。公开索引或 GitHub 代码不能单独支持
性能结论。流程和检查器见 [`docs/literature/README.md`](literature/README.md)。

## 每个分支的固定入口

```text
阅读 PROJECT_VISION.md
-> 创建 docs/tasks/<任务名>.md
-> 写明优先级、阶段门、问题、产物和最小验证命令
-> 关联已核验论文和配置
-> 实现最小可证伪实验
-> 运行检查与测试
-> 提交、推送、同步服务器并记录结果
```

分支只解决一个实验或基础设施问题。任务卡必须说明哪些内容仍是
`metadata-only`、哪些参数已测量、哪些结论不能外推。`preflight.sh local`
会检查分支和任务卡的对应关系。

## 阶段门禁

| 阶段 | 必须留下的证据 |
| --- | --- |
| 问题 | 假设、变量、基线、指标、安全边界 |
| 文献 | 日期化检索日志、全文来源、结构化笔记、研究空白 |
| 系统/机械 | CAD 和质量惯量、接触几何、限位、传感器坐标系和时序接口 |
| MuJoCo | 场景、固定 seed、观测/动作契约、smoke test |
| 训练 | 锁定环境、配置、数据划分、checkpoint、资源记录 |
| 评测 | 多 seed、基线、消融、失败案例和统计区间 |
| 迁移 | 实测噪声/摩擦/延迟、MuJoCo 标定、离线 replay、同一评测代码 |
| 真机 | 电机禁用测试、低速低增益、限位、watchdog、独立急停、操作员和回滚 |
| 发布 | 配置、环境锁、脚本、图表、公式、manifest、限制和负结果 |

只有完成前一阶段，才能进入后一阶段。`simulation-ready` 不等于
`transfer-ready`，更不等于 `hardware-ready`。

## 计算与数据分工

- 笔记本：代码编辑、轻量 MuJoCo、单元测试、可视化和未来的监督式真机
  调试。
- `research-gpu`：服务器上的 MuJoCo、训练、批量评测和大文件生成。当前
  是无 Slurm 的共享工作站，GPU 可见性不代表资源已预约；长任务必须等
  实验室调度器或明确的资源预约规则。
- `/mnt/research-data`：机械硬盘归档论文 PDF、数据、checkpoint、视频和
  运行日志；这些内容不进入 Git。
- GitHub：只同步源代码、配置、文档和小型文本指标。

服务器只使用 `gbu` 用户目录，不使用 sudo、不修改系统 CUDA/ROS、不安装
全局 Python 包，也不清理共享目录或结束他人进程。服务器流程见
[`workflow.md`](workflow.md) 和 [`server-inventory.md`](server-inventory.md)。

## 当前状态与下一步

- MuJoCo 平台中立接触、切向摩擦、双接触和两速率残差实验已经可复现。
- 两速率残差提案为 `simulation-ready`，但尚未达到迁移或真机门禁。
- 已有四篇带哈希的结构化论文笔记；中文三轴论文仍需通过学校门户下载。
- 下一步是补齐中文导纳、阻抗/混合位置力、人形多接触论文，并确定第一台
  真实机器人、F/T 传感器、控制器和通信接口。

论文 PDF 交接时只需提供本地路径、题目、DOI/数据库编号、正式来源、日期
和 SHA-256；硬件交接时提供型号、固件、限位、传感器标定、控制频率和急停
信息。Codex 会据此建立笔记、实验记录、配置和后续分支，不会索取账户密钥。

## 常用 Codex 请求

```text
阅读 docs/PROJECT_VISION.md 和对应任务卡，先检查文献证据边界，
实现一个 MuJoCo 最小可证伪实验，运行 preflight 和测试，
报告差异后提交到当前分支并推送 GitHub。
```

```text
使用学校门户下载的 PDF 路径，按 paper-note-template.md 完成中文翻译、
方法/公式、优缺点、实验设计、失败案例和 MuJoCo follow-up，
不要把 PDF 或门户凭据加入 Git。
```
